## 二、探头动作怎么做的

```css
/* ① 整个塔库（机器人 + 气泡）朝屏幕边靠过去 ② 机器人再单独往外沉 */
.taku-area.peeked.side-right { transform: translateX(30px); }
.taku-area.peeked.side-left  { transform: translateX(-30px); }
.taku-area.peeked.side-right .taku-robot { transform: translateX(46px) rotate(-24deg); }
.taku-area.peeked.side-left  .taku-robot { transform: translateX(-46px) rotate(24deg); }
```
- `rotate`：让脑袋朝屏幕里探、身体朝屏幕外沉，所以看着是"从边上探出头"，
  而不是被屏幕竖直切一半（竖直切 = 断头）。
- `translateX`：两段加起来 76px（桌面）→ 机器人约 6 成在屏幕外：
  **脑袋露一半、身体大半在屏幕外**（用户 2026-10-16 09:45 的要求：把斜着的半个身体和头缩到屏幕外）。
  调小 = 露得多，调大 = 藏得更狠。
- ⚠️ 浮动动画只能用 `translate` 属性（不能用 `transform`），
  否则动画会把探头的 rotate / translateX 整个盖掉。
- ⚠️ 说话时"啵"一下只加在**气泡**上（`.taku-dialog-box.talking`），
  绝不能加在机器人上：transform 动画会在动画期间把探头姿势顶掉，机器人会瞬间摆正又歪回去。

**"靠近边缘"才探头**：拖到屏幕中间时去掉 `.peeked`（站直），
松手吸附到最近一边后再加回来（js/takuEngine.js 的 `onMove` 里判断 80px 内）。

**说话时**：只换台词 + 气泡"啵"一下，`.peeked` 不动、位置不动 —— 永远保持探头。

## 四、JS 侧行为（js/takuEngine.js）

| 方法 | 现在的行为 |
|---|---|
| `initPeek()` | 贴右边 + 加 `.peeked`；点塔库 → 说句俏皮话 + 眼睛变红 |
| `keepPeeked()` | 保持探头状态（贴边时一直戴着 `.peeked`） |
| `speak(text, ms)` | 只换台词 + 气泡"啵"一下，**姿态、位置都不变** |

| 拖拽 | 抓机器人本体拖动；松手水平吸附最近一边（**高度保留，不会掉回底部**）；拖到中间自动站直 |
| 被戳（点一下不动） | 朝远离手指的方向退 46px（一格），姿势不变、位置记进 localStorage |

## 四.5、被戳一下 = 后退一格（不回到屏幕底部）

- 以前：点一下（没拖动）会把 `top/bottom` 清掉、重新贴边 → 塔库**啪一下掉回屏幕底部**，用户："不要直接到底部"。
- 现在：`stepBack(e)` 只做一件事 —— 朝**远离手指/鼠标**的方向退 **46px（一格）**；
  贴边时那个方向退不动（会被屏幕挡住），就改成朝屏幕里退一小步，反正不会原地不动。
- ⚠️ 三个坑：
  1. 方向要用**被戳的那只（`.taku-robot`）的中心**算。气泡在机器人左边，
     拿整个容器的中心算会把方向判反（从左边戳，它反而往左退）。
  2. 边界要用 `offsetWidth/Height`（布局尺寸），不能拿 `rect.width`：
     探头带了 translate/rotate 会把 rect 撑大，"往右退"就永远被判越界。
  3. 量位置前用 `.measuring` 临时关掉探头位移；**别摘 `.peeked`** ——
     那样一按下去塔库就突然站直，很跳。戳完仍按"离边缘远近"决定是否继续探头。
- 想改步长：`js/takuEngine.js` 里 `stepBack()` 的 `const STEP = 46`。

## 五、气泡的两档大小（字越多越长 / 用户动正文就缩回去）

| 状态 | 什么时候 | 表现 |
|---|---|---|
| 摊开（默认） | 塔库开口说话；鼠标回到塔库身上 | 宽度跟着字数走：短句短、长句长，最多 `min(420px, 34vw)` 才换行 |
| 缩成小条（`.compact`） | 用户在用正文：**滚动页面 / 点正文 / 划选文字** | 宽度缩到 118px（窄屏 96 / 84px），正文只留两行 + 省略号，让开正文 |

- JS 入口：`takuEngine.showBubble()` / `collapseBubble()`；
  监听 `scroll` / `pointerdown`（点在 `#taku-area` 上不算）/ `selectionchange`。
- 用户停手 **4 秒**后气泡自己摊开（免得缩着就再也不知道塔库说了啥）；塔库下一次开口也立刻摊开。
- `speak()` 里第一件事就是 `showBubble()`：说话时一定是摊开的，字越多气泡越长。
