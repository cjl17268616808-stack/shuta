# 数塔项目 · 新手引导改造报告

> 起因：用户反馈「数塔缺乏关键的引导，这让用户无从下手」
> 状态：✅ 已完成并通过真实浏览器验证

---

## 一、诊断：到底缺什么

我用 headless Chrome 实际渲染首页逐项排查，确认了 5 处引导缺失：

| # | 问题 | 证据 |
|---|---|---|
| ① | **章节列表根本没渲染出来** | `#stage children=0`，页面只剩主视觉大图 |
| ② | 使用指南藏在一张图后面 | 指南卡正面是与顶部 hero 重复的大图，用户不会想到要点开 |
| ③ | 没有「从哪开始」的指引 | 6 张章节卡权重完全相同，无推荐标记、无进度状态 |
| ④ | 塔库欢迎语 5 秒即消失 | 播完回到「等待指令中…」，无任何可操作提示 |
| ⑤ | 新题型没有玩法说明 | 排序/配对/填空等 8 种模式出现时，用户不知道要干什么 |

### 🔴 最关键的一条：章节列表丢失（问题①）

`renderChapters()` 末尾的 `this.stage.appendChild(listDiv)` **被误删**，
`listDiv` 建好却从未挂载到 DOM —— **首页一片空白，一张章节卡都看不到**。

这才是「无从下手」的根本原因：不是引导不够，是**入口整个没了**。

修复：恢复挂载，并加注释警示。

## 二、改造内容

### 1. 首屏新手引导浮层（新增）

首次打开自动弹出，塔库对话式，4 步讲清怎么玩：

1. **选一章开始爬** —— 从 VOL.1 开始，认准 🚩 标记
2. **跟着塔库一页页学** —— 点道具、按顺序点、配对、填空
3. **做完小测验就算通关** —— 进度自动保存，清缓存不丢
4. **想动手写 SQL？去「数塔之家」** —— 右上角真实数据库沙盒

底部带**个性化推荐**：「从 *第1章 · 初识数据库* 开始你的攀登吧！」
（依据 `findRecommendedStart()` 自动算出第一个未完成的知识点）

两个出口：`🚀 带我去开始`（直接跳转）/ `我先自己逛逛`（关掉浮层）。
看过一次即记录（`shuta_guide_seen`），之后不再打扰。

### 2. 「❓ 怎么玩」常驻入口

右上角新增按钮，随时可重看引导，不依赖缓存状态。

### 3. 章节卡：进度状态 + 推荐标记

| 元素 | 说明 |
|---|---|
| 🚩 推荐从这里开始 | 标在第一个未完成的章节上，红色描边高亮 |
| 🆕 还没开始 / 📖 学到 x/y / ✅ 已通关 | 三态徽标 |
| 进度条 | 按已完成知识点比例填充 |
| 动作文案 | 「点击开始阅读」/「继续第 N 节」/「点击复习」 |

### 4. 分镜内新题型玩法说明

8 种互动模式各配一句人话提示，显示在互动板顶部：

- 🔢 排序：「按正确顺序依次点击下面的卡片」
- 🔗 配对：「先点左边一个，再点右边一个」
- 🧩 填空：「点下面的词块，把它填进句子里的空格」
- 🔍 侦探：「把有问题的那几行揪出来点掉，没问题的别点」
- 🛤️ 抉择：「选一个做法看看后果，选错了可以重试」
- 🗂️ 分类 / 🎚️ 对比 / 🃏 翻卡：同理

### 5. hero 横幅点击看指南

主视觉下方加「👆 点我看使用指南」浮动提示，点击翻出完整指南覆盖层。

## 三、顺带修掉的两个隐患

### ① 章节卡可能永久不可见

`animations.css` 里 `.chapter-card` 的入场动画用 `backwards` 填充，
起始帧是 `opacity: 0`；**一旦动画因故不播放**（卡顿、降级渲染、reduced-motion），
卡片会永久停在透明状态——布局占位在、但什么都看不见。

修复：给 `.chapter-card` 加显式 `opacity: 1` 兜底，并新增
`@media (prefers-reduced-motion: reduce)` 分支彻底关闭动画。

### ② CSS 文件损坏

排查过程中发现 `style.css` 有一处规则被截断（`.welcome-front img {` 缺右花括号），
导致**其后所有 CSS 全部失效**——这也是引导浮层一度渲染错位的原因。
已修复并新增括号平衡校验（`.workbuddy/cssbal.js`）。
