## 三点十、T14 提交后空白问题修复 ✅【最高优先级】

**现象**：提交到竞赛平台后内容与模块全部不见，塔库卡在「系统启动中...」。

**根因**：竞赛平台预览是**沙盒 iframe**，其中 `localStorage` 访问抛 `SecurityError`；
`takuEngine.initDrag()` 未保护地读 `localStorage` → 异常冒泡出 `main.js` 的 **async** 启动回调
→ 变成**被静默吞掉的 Promise rejection**（`window.onerror` 抓不到）→ 后续 `renderChapters()` 永不执行。

**修复**
1. `takuEngine.js`：2 处 localStorage 访问加 try/catch
2. `main.js`：启动流程重写为**每步独立容错**，任一环节失败都不影响内容渲染
3. 新增 `window.__shutaBootErrors` 与 `unhandledrejection` 监听（同类问题以后可见）
4. 交付包瘦身：**22.77 MB → 8.9 MB**（移出误打包的 12.7 MB 未压缩原图）
5. 修复 `style.css` 一处孤立规则导致的括号失衡

**验证**（交付包解压后实测）
| 环境 | 结果 |
|---|---|
| 沙盒（localStorage + AudioContext 禁用） | ✅ 6 章渲染 / 数塔之家可开 / 8 表 53 行 / 封面 6-6 / 零错误 |
| 正常环境 | ✅ **193/193 分镜通关，0 问题，0 JS 报错** |

**详见**：[提交空白问题排查报告.md](提交空白问题排查报告.md)

## 三点十一、T15 响应式挤压测试 ✅

**目标**：整个项目在窄屏下「变小、变好看、还能正常用」。

**🔴 关键发现**：**1024px 以下全部页面横向溢出**（360px 时溢出 24px，右侧内容被切）。
根因：`body` 是 `display:flex`，而 `.comic-bg-decor` 背景装饰层**没有定位规则**，
变成真实弹性子项白占 66px，把 `#app` 向右挤了 53px。

**修复**：给装饰层补 `position:fixed; inset:0`，脱离文档流。
→ 4 个页面 × 5 个宽度（360/414/600/768/1024）**全部不再溢出**。

**另外 3 处体验修复**
| 问题 | 修法 |
|---|---|
| 顶部按钮窄屏堆 4 行 | 长文案收成图标 → 压到 2 行 |
| 塔库浮层遮挡章节卡 | 窄屏缩小机器人 + 内容底部留白 150px |
| 讲解气泡超窄屏挤成一条 | ≤480px 头像移到正上方，正文占满整行 |

**验证**：交付包解压后，360px 窄屏 + 沙盒环境双重实测通过；

## 三点十二、T16 塔库贴边探头 ✅

**需求**：塔库在页面边缘时**斜着身子**探头，气泡保留但不要挡住正文（参考市面悬浮插件）。

**设计**（对标 Intercom / Crisp）
| 状态 | 触发 | 表现 |
|---|---|---|
| 探头 | 默认空闲 | **整个机器人斜着探出身来**（左 +28°/右 −28°，绕自身中心转），斜靠边缘、大半身子在屏幕外；气泡保留、收窄到 230px |
| 滑出 | 悬停 / 点击 / 说话 | 头身完整、摆正，气泡恢复常规宽度 |
| 自动收回 | 说完 1.4s / 移开 0.9s | 回到探头姿态 |
| 拖拽吸附 | 松手 | 水平吸附最近一边再探头 |

**🔑 关键点一**：气泡原本 `pointer-events: auto`，浮在内容上还吃点击，
导致「看得见点不到」。改成 `none` 后实测 **12/12 采样点全部穿透到下层内容**。
所以气泡即使在探头态也保留着，完全不影响操作正文。

**🔑 关键点二（大坑）**：`.taku-robot` 原本挂着 `animation: float`，
而它的 keyframes 用的正是 `transform` —— **CSS 动画会覆盖普通声明**，
我加的 `rotate(-17deg)` 会被彻底盖掉（真实浏览器 100% 发生，headless 禁动画时反而看不出）。
修法：把浮动改用独立属性 `translate`，把 `transform` 让出来给旋转。

**顺带修复**：`.hero-banner` 用 `92vw` 导致桌面端有滚动条时横向溢出 → 改为 `width:100%; max-width:860px`。

**验证**
- 状态机 6 个状态转换全部正确
- 探头态旋转 ±28°、滑出态旋转 0°（摆正）；气泡 `pointer-events:none` 保证点击穿透

**改版说明**：第一版"竖直切一半"生硬，第二版"隐藏身子只留脑袋"头身分离 —— 都不对；
第三版才是**整个身子斜着探出**（用户给兔子示意图后确认的方向）。
- 断点位移：360px→-34px、700px→-40px、>768px→-62px
- 交付包 360px 窄屏 + 沙盒实测通过
- 全量通关测试 **193/193，0 问题 0 JS 报错**
