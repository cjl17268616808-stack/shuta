## 二、功能特性

### 1. 漫画式内容呈现
- **双栏布局**：左讲解 + 右漫画场景，图文对照
- **139 张人工手写 SVG 分镜漫画**（几何图形 + emoji + 粗描边）
- **32 张小节封面**：从《数塔世界》总览路线图逐格切分
- 每章不同背景色、不同漫画氛围，拒绝「一招鲜」

### 2. 收集式互动
- 右侧漫画场景里散落着**可点击收集的道具**（黄色便签、橙色表头等）
- 全部捡起才解锁「继续」按钮 —— 看得进去，才走得下去

### 3. 塔库 —— AI 向导机器人
- **贴边探头**：塔库贴在屏幕边缘时歪着身子探出头（脑袋朝里探、身子探出屏幕），
  说话时保持这个姿态，**不会**整个滑出来挡内容；拖到屏幕中间则站直
- 气泡 = 塔库说话的可视化：字越多气泡越长；用户一滚正文 / 点正文 / 划选文字，
  气泡就缩成小条让开内容（停手 4 秒或塔库再开口又摊开）
- 气泡右上角挂塔库的漫画大头贴；气泡不吃点击，正文该点点、该选选
- 实时跟随讲解；气泡不吃点击，正文该点点、该选选
- 拖它能换位置（松手水平吸附到最近一边，高度保留）；戳一下只朝反方向退一小步，不会掉回屏幕底部
- **语音讲解**：浏览器原生 Web Speech API 现场合成（3 中文 + 3 英文声线）
- 点击脑袋有彩蛋

### 4. 守门怪小测验
- 每节末尾有小测验，答对撒彩带 🎉，答错塔库再讲一遍

### 5. 数塔之家 —— SQL 实战沙盒
- 内置 **sql.js（SQLite → WebAssembly）**，离线可跑真 SQL
- 左侧 tab 切换「选小节 / 实战任务」，中间 SQL 控制台
- 64 张 SQL 任务卡：空库判失败、标准答案判通过

### 6. 学习进度自动保存
- 进度存本机浏览器（内嵌基线 + 缓存合并）
- 清缓存、换电脑不丢；支持随时重置
- 「AI 日志」章节实时读取进度，学完一节日志多一条

### 7. 声音系统（零音频文件）
- 背景音乐：Web Audio API 按乐谱规则**现场合成**
- 可换声线、调速、调音调、调音量、上传自己的 MP3

## 四、打包与提交

### 4.1 一键打包

项目根目录双击 `pack.bat`，或命令行：

```bash
cd E:\XM\shuta
powershell -ExecutionPolicy Bypass -File tools\pack.ps1
```

| 命令 | 作用 |
|---|---|
| `pack.bat` | 标准离线包（默认） |
| `pack.bat full` | 完整包（额外含 AI 原始素材 + 画布文件） |
| `pack.bat force` | 跳过「内容未重编译」检查，用当前 data.js 直接打包 |
| `pack.bat MyName` | 自定义 zip 文件名 |

打包脚本自动完成 5 件事：
1. **预检**：必需文件是否齐全、内容源码是否比 js/data.js 新
2. **刷版本号**：所有 js/css 引用自动加 `?v=时间戳`（解决缓存）
3. **生成 zip**：路径统一正斜杠（保证别人解压不乱）
4. **自检**：反斜杠 0 个、垃圾文件 0 个、关键文件齐全
5. **输出**：`数塔YYYYMMDD.zip` 在项目根目录

> 输出 zip 解压后双击 `index.html` 即可离线运行，可直接上传比赛平台。

### 4.2 开发流程（改了内容后）

```
1. 改内容  → 编辑 python_src/chapterN.py（结构化源数据）
2. 编译    → cd python_src && python build_data.py（生成 js/data.js + data/textbook.json）
3. 校验    → 跑 .workbuddy 下的三套校验脚本（见下）
4. 预览    → 本地服务器跑通
5. 打包    → pack.bat（若报"内容没重编译"，先跑 build_data.py）
```

### 4.3 内置校验脚本

| 脚本 | 检查内容 |
|---|---|
| `.workbuddy/verify-content.mjs` | 分镜数、正文字数、互动模式完整性、插画是否存在 |
| `.workbuddy/verify-tasks.mjs` | 64 张 SQL 任务卡：空库必须判失败、标准答案必须判通过 |
| `.workbuddy/render-all.html` | 全量自动通关：遍历 193 个分镜自动作答，检测死路与 JS 报错 |

## 六、常见问题（FAQ）

**Q：双击 index.html 打不开 / 内容空白？**
双击打开用的是内置 data.js，不需要服务器。若空白，按 F12 看 Console 报错——大概率是浏览器拦截了本地脚本，换 Chrome / Edge 新版即可。

**Q：比赛沙盒里章节加载不出来？**
数据加载已做沙盒兼容：`fetchData.js` 内置数据优先，不依赖 fetch，沙盒 iframe 也能正常渲染。

**Q：塔库不说话？**
语音用浏览器 TTS。首次点击页面任意处解锁音频；若设备无声线，自动降级为文字模式（按钮变灰）。

**Q：数塔之家 SQL 跑不动？**
sql.js 已内置 WASM（内联 base64 + fetch 双通道），离线可用。若报错请用新版 Chrome / Edge。

**Q：进度会丢吗？**
进度存本机浏览器 localStorage。清浏览器缓存、换浏览器、隐私模式会重新开始；换电脑不迁移。设置面板可一键重置。
